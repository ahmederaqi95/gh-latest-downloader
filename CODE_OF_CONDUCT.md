# Code of Conduct

We want this project to be a friendly, respectful place for everyone.

## Expected behaviour

- Be kind and patient, especially with people who are new.
- Give and accept constructive feedback gracefully.
- Assume good intent and focus on what is best for the project.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Publishing other people's private information.
- Spam, trolling or deliberately disruptive behaviour.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break these rules, and
may block repeat offenders. To report a problem, contact the maintainers through a private
GitHub security advisory or the contact details on their GitHub profile.
